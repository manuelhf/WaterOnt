Where the data come from

From the EPANET model (.inp)Layout, lengths and diameters; simulated pressures and flows; hydraulic criticality; supply zones; sensors marked in the file; customer demand types.
Synthetic unless you supply themInstall year, material, condition grade, last inspection, failure history, soil, and hospitals, schools or care homes.
Assets assessedPipes only. Pumps, valves, tanks and reservoirs take part in the hydraulics and appear on the map, but receive no condition, risk or maintenance decision.

Pressure sensors

A pipe counts as monitored when a pressure sensor sits within two links of either end. Monitoring feeds rule R5, which sends critical, high-risk mains that nobody is watching for inspection, and the questions about unmonitored mains. Add or remove sensors to see how coverage and decisions change.

Update asset records here

Import an asset register to replace synthetic facts with real ones. Only the columns and cells you fill in are used; blank cells keep the current value. Write none in failure_years for a pipe with no recorded failures. The file stays in your browser.

Rebuild with Python or Colab

Some data change the hydraulics or the network itself, so they need a rebuild:

A new network
--inp mynet.inp
Asset register
--assets register.csv
Dated failures
--failures failures.csv
Critical customers
--facilities facilities.csv
Your policy text
--guidelines policy.json

Then python -m wateront web --json --out mynet.json … and open the file here with Open network file (.json)…. Without Python, use the one-click converter in Google Colab: upload your .inp and any CSV files, press Run, and download the .json. An asset register saved from this page can go straight back into --assets.

Use your own EPANET model

  1. Choose your files. Your model (.inp) and, if you have them, CSV files with your data: an asset register or inspection log, a failure list, a sensor layout, or critical customers. Column names need not match the templates exactly.
  2. Copy the code and run it in Google Colab. Press Copy code, then Open Google Colab, paste into the empty cell (Ctrl+V, ⌘V on a Mac) and run it (Shift+Enter). It needs a Google account and takes about a minute. Your files are inside the code and are processed only in your own Colab session.
  3. Open the result here. Colab downloads a network file (.json): open it with Open the downloaded file.
